# 雪地庇护所与火源：调研笔记 v0.1

> **用途**：给 `CORE_GAMEPLAY.md` 里的 `[REAL]` 标注提供依据。
> **可信度说明**：本笔记基于 2026-10-05 的网络检索摘要。来源以户外/野外生存类网站为主（AMC outdoors.org、Wikipedia、Cascade Designs、Backpacker、Scout Life、NPS 等），**没有逐篇核对原文**。数值请理解为"野外指南常见量级"，不是工程标准。
> 游戏里实际使用的数值一律标 `[TUNE]`，可以偏离这里的数字，但不能违背这里的**方向**。

---

## 1. 雪深 → 能做什么庇护所

| 现场雪深 | 现实中可行的做法 | 来源中的常见说法 | 对游戏的含义 |
| :--- | :--- | :--- | :--- |
| **< 0.3 m** | 雪不够用来挖。只能做**非雪庇护所**（倒棚 / 枝叶棚 + 火），或者把周围的雪全部堆起来做 Quinzhee | — | 火成为主要保暖手段 |
| **0.3 – 0.6 m** | **浅坑**：往下挖到地面也只有半身深，必须**往上加墙**（雪块或堆雪）再盖顶（树枝 / 雪块 / 防水布）。保暖和防风都弱 | Cascade Designs："雪浅时可以做浅沟，用附近切下的雪块往上砌墙或搭 A 字顶" | 你说的"坑状"基本正确。但它不是"挖下去"，而是"挖一点 + 砌上来"，工时不一定短 |
| **约 0.9 – 1.2 m** | **标准雪沟**（Snow Trench）：挖一条比身体略长、比睡垫略宽的沟，顶部用雪块或树枝封住 | 多个来源："约 3–4 英尺雪深" | Snow Trench 的门槛应在这个量级，不是 0.8 m 以下 |
| **≥ 1.2 – 1.5 m** | **雪洞**（Snow Cave）：横向掏进雪堆或雪坡 | 多个来源："至少 4–5 英尺（1.2–1.5 m）" | 你说的"≥1.5 m 可以做雪屋"成立，而且偏稳妥 |
| **约 ≥ 2 m（深雪檐 / 背风雪堆）** | **高床雪洞**：要同时放下冷气坑、高床、≥30 cm 顶厚，需要更多垂直空间 | 来源没有给出单一数字；这是由几何推出来的 | `[GAME]` 推论，参考图 "~2.1 m" 与此一致 |
| **与地面雪深无关** | **Quinzhee**：把雪堆成约 1.5–2.5 m 高的雪丘，等它**烧结 60–120 分钟**，再掏空 | Wikipedia、AMC：不需要原生深雪，只需要够多的松雪；必须等烧结 | 对我们这个只有 2 小时日照的局非常不划算 → 适合作为"时间陷阱"选项，MVP 暂不做 |

## 2. 顶厚与通风

- **顶厚 / 壁厚**：常见下限约 **30 cm（1 英尺）**，较保守的建议是 **60 cm**。
  → 参考图写的 "Roof thickness ≥ 1.5 m" **不对**，1.5 m 是总雪深量级，不是顶厚。M4 重绘主视觉时需要修正这个标注。
- **校验技巧**：挖之前从外面往顶部插约 30 cm 长的木棍，从里面挖到木棍尖就停 `[REAL]`。这可以做成游戏里的一个"读数"细节。
- **穹顶**：平顶容易塌，穹顶更稳；把内壁抹光可以减少滴水 `[REAL]`。
- **通风孔**：必须在顶部戳一个小通风孔，防止 CO₂ 积聚；风雪天要出去清理被堵住的孔（NPS：<https://home.nps.gov/mora/planyourvisit/winter-safety.htm>）`[REAL]`。

## 3. 火与烛灯

| 场景 | 现实做法 | 游戏规则 |
| :--- | :--- | :--- |
| 雪庇护所内（雪洞 / 雪沟 / Quinzhee） | 不生火取暖：耗氧、产生 CO、融化顶棚 | `[REAL]` 禁止 |
| 雪庇护所内的烛灯 | 有人用来照明，但要求有通风孔，并且**不能点着睡觉**；更推荐头灯 / LED | `[GAME]` 允许作为醒着时的照明和氛围，入睡时熄灭，不提供热量 |
| 倒棚（Lean-to）+ 反射火 | 经典冬季求生组合：棚背对风，火在开口前，火后面用生木或石头砌约膝高的反射墙。**通宵烧需要大量木柴，天黑前就要备好** | `[REAL]` MVP 候选的第 4 种方案（见 CORE_GAMEPLAY §5） |
| 帐篷 / 泥屋 / 石屋 | 可以在里面生火；**封闭空间必须用炉子 + 烟囱** | `[REAL]` MVP 之后再做 |
| 雪庇护所外的篝火 | 睡前暖身、烘干手套袜子、融雪取水 | `[GAME]` 提高入夜时的状态，不整夜供热 |

## 4. 一个需要避开的误区

**树井（Tree Well）**：有些资料把云杉根部的雪坑当天然庇护所，但它是**雪埋窒息**的高发地点，掉进去的人大多无法自救。
→ 游戏里如果出现树井，应该作为**危险地形**教学，而不是推荐的庇护所。
