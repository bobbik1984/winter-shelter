## A. 夜晚（直接决定 D14"可玩的夜晚"）

| # | 观察 `[OB]` | 游戏含义 |
| :-- | :--- | :--- |
| A1 | 没有现代睡袋时**每 2–3 小时醒一次**（例：2:00、3:00、4:30、6:00）。 | 💡 夜晚不是一次性结算：快进播放、冷醒是常态而不是失败。 |
| A2 | **"You don't freeze to death without waking up at least once."** 冻醒后必须起来活动，不能躺着硬睡。 | 💡 **设计规则**：失温致死之前，玩家**至少醒来一次、有机会行动**。这给了容错，也符合 Hard ≠ Obscure（不会在睡梦中莫名其妙死掉）。 |
| A3 | 醒来原因：①火灭 / 炉凉；②局部冷（脚露出皮毛碰到冰面、湿袜子）；③大雪压顶（帆布积雪有塌的危险）；④狂风震动雪洞顶。 | 💡 冷醒事件表：火灭 → 添柴；湿脚 → 烘袜子 / 塞怀里；积雪压顶 → 从内部顶落；（雪洞）通风口被雪堵 → 清通风口。 |
| A4 | 醒来后的行动：添**预先烘干**的柴；把冻硬的靴子、湿袜子拿到火边或塞进怀里；用棍子从里面顶帆布除雪；调整兽皮和热水瓶。 | 💡 夜间可选行动都依赖白天的准备（备柴是否烘干、有没有热水瓶）——"Make a Plan"延伸到夜里。 |
| A5 | 热水瓶（灌开水）放进皮毛 / 睡袋里暖床。 | 💡 睡前道具：融雪烧水 → 热水瓶，前半夜加热（我们已有"热饮"，可扩展）。 |

## C. 庇护所与自然条件（印证 D13 §9.3 "地物 + 少量劳动"）

| # | 观察 `[OB]` | 游戏含义 |
| :-- | :--- | :--- |
| C1 | 树根球（root ball）当防风墙和热量反射板，挖开它前面的雪坑。 | ✅ 倒棚依托树根盘 + 反射火。 |
| C2 | 深雪掘地（dugout）：6–8 ft 雪里向下挖坑，两侧雪壁挡风，顶盖帆布。 | ✅ 雪沟；💡 深雪里的"深雪沟"变体（顶要有坡度，见 C6）。 |
| C3 | 雪洞 / Quinzee：S 形入口或低矮入口让冷空气沉在下面，**床必须高于入口**。 | ✅ 高床雪洞（冷气坑 + 睡台）规则。💡 S 形入口可作为挡风加分。 |
| C4 | 树井与低垂云杉枝：暴风雪中天然挡风空腔。 | ✅ S5 树井庇护所。 |
| C5 | **解冻地面庇护所**：清雪露出土 / 沙石，大火烤 3–4+ 小时把冻土烤干，炭火埋在沙石下，睡在 70°F 以上的温热地面上。 | 💡 新庇护所候选：**埋炭热床**。需要：沙石 / 河滩（湖岸地形！）、大量木柴、长时间。失误：选在低洼处，融雪积水变泥塘（C8）。 |
| C6 | 帆布搭得太平，积雪滑不下来，几乎压塌。 | 💡 屋顶坡度：雪沟 / 树井的枝条顶在大雪夜有"压顶"事件（夜间可清理）。 |
| C7 | 丛林高架床（bushcraft cot）：床离冰面几英寸，底下比冰面暖近 10°F。 | ✅ "离开地面 / 冷空气"加隔冷分。💡 倒棚可加"高架床"阶段（木头 + 枝条）。 |
| C8 | 烤地解冻时周围融雪流向低处，睡处变成冰冷泥塘。 | 💡 选址教训：热床不能选在低洼处（报告可解释）。 |

## D. 建造时间（⚠️ 与现有数值冲突）

| # | 观察 `[OB]` | 现在游戏里 | 处理建议 |
| :-- | :--- | :--- | :--- |
| D1 | 大型雪洞（挖出约 12 立方码 ≈ 一卡车雪）**5 小时**。 | 基础雪洞 95 min、高床雪洞 135 min | 他挖的是多人大洞；单人小雪洞文献约 45–90 min（`research/` 旧条目）。我们的数值在单人范围内，**保留但标 `[GAME]` 压缩**，并在 research 里写清依据。 |
| D2 | 基础营地 + 伐木建墙 3–5 小时。 | 倒棚约 55 min | 明显压缩。`[GAME]`：一局只有一个下午。 |
| D3 | 解冻地面 3–4+ 小时连续烧火。 | （没有） | 若做 C5，必须是"开工最早 / 柴最多"的路线。 |

> 结论：时间是我们**有意压缩**的（一局 10–20 分钟），但**相对顺序**必须真实：树井 < 雪沟 < 倒棚 ≈ 小雪洞 < 高床雪洞 < 热床。现状基本符合。

## G. 原则级引用（可进 VISION / 野外手册）

- **三样只受一样**："I don't mind being cold, I don't mind sleeping on the ground, and I don't mind being hungry, but I only do one of those things at a time." → 设计原则：一局里玩家可以缺一样（冷 / 地面 / 饿），缺两样就危险——可作为报告的高层归因。
- **冻醒必动**："You don't freeze to death without waking up at least once." → A2。
- **自律**："This survival stuff is really a lot of work…" → 野外手册引语。
